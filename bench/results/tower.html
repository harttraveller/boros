What is being measured

boros tokenizes, parses and compiles Python into a tree of Python closures and runs them; it never calls the host's eval, exec or compile. Because it is written in the Python it implements, it can run its own source. At level n, every operation of the benchmark is carried out by closures of level n, which are carried out by closures of level n−1, and so on down to CPython.

Start-up grows too: before running anything, each level parses and compiles the interpreter's own source while being interpreted itself, so the start-up column multiplies by roughly the same factor per level.

uv run python -m boros -m boros -m boros bench/simple_statement.py   # the same thing
